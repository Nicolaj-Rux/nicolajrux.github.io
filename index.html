I am a PhD candidate in Mathematics at Chemnitz University of Technology. My supervisor is Prof. Dr. Sebastian Neumayer.

My research interests include functional analysis, Fourier analysis, reproducing kernel Hilbert spaces, and kernel methods. I am particularly interested in efficient numerical methods for kernels and related variational problems.

I also work on Python and CUDA programming for fast and practical implementations of kernel-based algorithms and numerical methods.

Repositorys & Projects

2026 Weighted absolute value sumation
Time- and memory-efficient CUDA/C++ implementation for large-scale weighted absolute value summations, supports batching and gradients, exposed as a PyTorch extension.
For q in R^(D x N), k in R^(D x M), v in R^(N x C) computes:
            out[m,c] = Σ_{d=0}^{D-1} Σ_{n=0}^{N-1} |q[d,n] - k[d,m]| · v[n,c]
Code aviable on [GitHub]

2025 Kernel Slicing
Pytorch implementation for numerical inversion of Slicing operator
For given function F inverts the Slicing Operator S_d : L^2([0,1]) -> L^2([0,1]) defined as 
            F(s)=(Sf)(s) = ∫_0^1 f(t·s) ρ_d(t) dt with ρ_d(t) = c_d (1 - t^2)^((d-3)/2)
Code aviable on [GitHub]
